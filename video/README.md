# Відеопрезентація грантоЇД.АІ

Гайд по використанню. Remotion, 1920×1080, 30 fps, дванадцять сцен, ≈120 секунд,
українською.

```bash
cd video
npm install
npm run dev      # Remotion Studio — живий перегляд і правки
npm run render   # → out/hrantoid.mp4
npm run still    # один кадр, швидше за повний рендер
```

## Що всередині

`src/theme.ts` — палітра, скопійована з `packages/ui/tokens.css`. Не вигадана:
презентація, яка виглядає як інший продукт, привчає глядача впізнавати не те.
Якщо токени змінюються, це змінюється разом із ними.

`src/components/ui.tsx` — спільна типографіка й рух. Словник руху навмисно
вузький: з'являється з підйомом, лінії малюються зліва направо, нічого не
пружинить. У продукту тривалості 120–200 мс і одна крива — презентація, яка
підстрибує, рекламувала б інший софт.

`src/scenes/*` — по сцені на файл. `src/MainVideo.tsx` — порядок і тривалості.

`public/shots/*.png` — знімки працюючого застосунку з живою базою. Не відтворені
макети: у гайді має бути та кнопка з тим підписом, який людина шукатиме очима.
Компонент `Shot` обводить один елемент рамкою без заливки, бо заливка ховає саме
те, на що вказує.

Щоб оновити знімки після зміни інтерфейсу, зніміть екрани заново й покладіть під
тими самими іменами. Координати рамок у сценах задані в пікселях самого знімка,
тож після перезнімання їх треба звірити.

## Звідки цифри

Усе, що звучить як факт, узяте з реального прогону, а не написане для ефекту:

- **20 → 8 → 11 → 1** — один `npm run nightly` проти ГУРТ і Громадського Простору.
- **Цитати у сцені «Доказ»** — дослівно з умов Stanley 1913 Creators Fund, як їх
  прочитала система, і з профілю демо-організації. Вердикт там «Невідомо», а не
  «Підходить», бо саме це підтверджують ці два рядки.
- **Три відмови** у сцені «Чого воно не робить» — реальні випадки, кожен тепер
  закритий перевіркою в коді.

Змінюючи копію, звіряйте з продуктом. Сцена, яка обіцяє більше, ніж софт робить,
— це той самий дефект, від якого софт захищається.

## Шрифт

Inter, той самий файл, що самохоститься в застосунку (`public/inter-variable.woff2`).
Вантажиться через `delayRender`, щоб рендер його дочекався. Archivo з брифу тут
не підійшов би: у ньому немає кирилиці, а знак — переважно кирилиця з великою Ї
посередині.
